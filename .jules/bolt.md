## 2025-02-28 - [Refactoring O(N*M) Search Loops with break statements]
**Learning:** When refactoring O(N*M) nested search loops that use a `break` statement into O(N) pre-computed dictionary lookups, directly assigning values using a dictionary comprehension (e.g., `{item['key']: item for item in list}`) maps to the *last* matching item if duplicates exist. This breaks the *first-match* behavior of the original loop with the `break` statement.
**Action:** To correctly preserve first-match semantics when building O(1) lookup dictionaries, populate the dictionary iteratively checking `if key not in dict:` to only register the first occurrence of each key.
